# Google Play Release Notes

Version: 1.0.19+52  
Date: 2026-05-14

## Primary (Recommended)
This update introduces the new NFT Identity system with economic verification logic:
- Added NFT Identity profile creation and updates in Wallet.
- Identity unlock is now tied to real protocol milestones (session progress + first successful settlement), not cosmetic-only actions.
- Added public profile verification support for wallet-based identity viewing.
- Improved profile avatar propagation so NFT avatar can be used across wallet/profile surfaces.

Additional reliability improvements:
- Improved token/session resilience and corruption handling.
- AI support token flow is now optional-safe for release builds.
- Stability and performance hardening across mining/session backend paths.

## Short (Backup)
New NFT Identity system is live: create and update your on-chain style identity after eligibility milestones. Added public profile verification support, improved avatar sync across wallet/profile, and delivered stability improvements for token handling, AI support flow, and core mining/session reliability.
